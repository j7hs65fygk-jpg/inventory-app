# 在庫管理アプリ

このリポジトリには、ブラウザ上で動作するシンプルな在庫管理アプリを追加しました。

## 主な機能
- 商品の追加
- 商品一覧の表示
- 商品の編集
- 商品の削除
- 在庫数と総額の集計
- 検索機能
- ローカルストレージによる保存
- 要補充の表示

## 使い方

1. リポジトリをブラウザで開く
2. `index.html` を直接ブラウザで開く
   - 例: ファイルをダブルクリック
3. もしくはローカルサーバーを起動して表示する

```bash
python3 -m http.server 8000
```

その後、ブラウザで http://localhost:8000 を開いてください。

## ファイル構成

- `index.html` - アプリの画面構造
- `styles.css` - スタイル定義
- `app.js` - 在庫管理ロジック
